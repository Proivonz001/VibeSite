For the past few months I have been building things with AI coding assistants: games, trading tools, MCP servers, small utilities. Most of them lived in folders on my desktop, which is a poor place for software to live.

This site fixes that. Every project gets a page with what it is, how it was built, and a link to the source code when it is public. Some projects will also be playable directly in the browser, and a few will be for sale.

The blog is where I keep notes on the process itself: what worked, what did not, and the small tricks that made a difference. If you are curious about building software with AI, that is the part to follow.

The site itself was built the same way, in a single afternoon, with Next.js and Claude Code.
